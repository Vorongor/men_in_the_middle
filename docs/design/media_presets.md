## 1. Брендинг

Майстер-арт лежить у `assets/branding/` і **не бандлиться як runtime-асет** —
обидва генератори роблять із нього нативні ресурси платформ на етапі конфігурації.

| Файл                          | Розмір    | Призначення                          |
| ----------------------------- | --------- | ------------------------------------ |
| `app_icon.png`                | 1024×1024 | legacy-іконка Android + Windows .ico |
| `app_icon_foreground.png`     | 1024×1024 | foreground adaptive-іконки Android   |
| `splash_logo.png`             | 768×768   | лого splash-екрана                   |

**Джерело:** згенеровано зі спрайта `assets/images/hacker/hacker_green.png` (819×819)
— оригінальний арт власного дизайнера проєкту — на фоні `#0A0A0C`.
Рішення власника від 2026-07-18. Спрайт масштабовано до 72% для
legacy-іконки і до 55% для adaptive-foreground — маска лончера обрізає приблизно до
центральних 66%, тож foreground свідомо менший.

**Регенерація після зміни арту:**

```
dart run flutter_launcher_icons
dart run flutter_native_splash:create
```

Конфіги обох — у `pubspec.yaml`, секції `flutter_launcher_icons:` і `flutter_native_splash:`.

> ⚠️ `flutter_native_splash` цієї версії **не приймає ключ `windows:`** — падає з
> «not a valid parameter». Splash налаштований для Android (+ згенеровані iOS/Web
> ресурси); Windows-раннер білого спалаху не дає, тож і фіксувати нема чого.

## 2. Музика

**Джерело всього аудіо:** Pixabay (<https://pixabay.com/music/>,
<https://pixabay.com/sound-effects/>), Pixabay Content License — атрибуції не
вимагає. Уся графіка — оригінальний арт дизайнера проєкту. Деталі — `CREDITS.md`.

| Файл                                  | Призначення                        | Стан |
| ------------------------------------- | ---------------------------------- | ---- |
| `main_theme.mp3`                      | меню, auth                         | ✅ `playMenuTheme()` |
| `background_tracks/01,02,…,08,10`     | плейлист хаба, 9 унікальних треків | ✅ `playHubPlaylist()` |

**`09_ingame_back.mp3` видалено** — був побайтовою копією `01` (той самий MD5),
тобто ~5.8 МБ дубля у білді. Рішення власника від 2026-07-18.

**Логіка плейлиста** (`AudioService`): shuffle без повтору підряд, включно зі стиком
між колами — при перетасовці новий перший трек не може збігтися з попереднім останнім.
Перехід на наступний — по `onPlayerComplete`.

> Технічна деталь: `Bgm.play()` у flame_audio жорстко ставить `ReleaseMode.loop`,
> тому `onPlayerComplete` ніколи б не спрацював. `AudioService` після кожного
> `play()` повертає `ReleaseMode.release` — саме це й рухає плейлист.

## 3. Звукові ефекти

Клипів у паку **5**, а хуків у коді більше, тож частина хуків свідомо ділить клип.
Мапінг зібрано в одному місці (`AppAudio`, секція «Semantic aliases»), а не по
call-site'ах — щоб заміна на власний клип була однорядковою.

| Клип                | Пряме призначення                    | Хуки, що його ділять        |
| ------------------- | ------------------------------------ | --------------------------- |
| `mouse-click.mp3`   | будь-яка навігація (push роуту)      | `sfxCatch`, `sfxPurchase`   |
| `button.mp3`        | LAUNCH ATTACK                        | `sfxHit`, `sfxLose`         |
| `message_sound.mp3` | level-up                             | `sfxWin`, `sfxUpgrade`      |
| `keyboard.mp3`      | **луп** на весь час екрана атаки     | —                           |
| `light-switch.mp3`  | перемикач Mute All, прев'ю гучності  | —                           |

**Клік на навігації** підключено не по кнопках, а через `AudioRouteObserver`
(`NavigatorObserver` у `MaterialApp`) — одна точка вмикання/вимикання замість ~50
ручних викликів. Той самий обсервер перемикає музику меню ↔ хаб.

**Луп клавіатури** грає на окремому `AudioPlayer` (`FlameAudio.loop`), інакше він
витіснив би музику — вони звучать одночасно за задумом. Старт в `initState`
екрана атаки, стоп у `dispose` (покриває finish, abort і системний back),
пауза разом із `pauseEngine` при згортанні застосунку.

### Прогалини — в анкету плейтесту (крок 09)

Міні-гра не має власних catch/hit/win/lose; покупка й апгрейд ділять клипи з іншими
діями. Якщо тестери скажуть, що звук «одноманітний» — доукомплектувати пак.

## 4. Гучність

Формула незмінна: `general × music` і `general × effects`, `Mute All` → 0.
Крок 07 додав:

- `applyVolume()` тепер застосовує гучність і до лупа, не лише до музики;
- Settings застосовує зміни **наживо** (раніше — лише при виході з екрана);
- луп стартує навіть при нульовій гучності, щоб піднятий посеред атаки слайдер
  спрацював одразу, а не з наступної атаки.
