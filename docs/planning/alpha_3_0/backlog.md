# Беклог Alpha 3.0

Знахідки й ідеї, свідомо відкладені за межі Alpha 2.0. Не «забуте» — **вирішене
відкласти**, із зафіксованою причиною.

## Код-рев'ю кроку 02 (04.07.2026) — відкладено рішенням власника

Стосуються логіки цілей і контрактів; правити їх усередині альфи ризикованіше,
ніж лишити, бо кожна зміна зачіпає баланс, який щойно відкалібрували.

| # | Знахідка | Чому відкладено |
| - | -------- | --------------- |
| 1 | Honeypot може зайняти слот страхового контракту — гравець із 0 балансу отримує «рятівний» контракт, який є пасткою | Зачіпає генератор контрактів; потребує перебалансування разом із honeypot-механікою |
| 2 | Floor на індексі 0 у `refreshContracts` — «легкий» слот жорстко перезаписується сумісним шаблоном, а не обирається чесно | Переписування селектора шаблонів; ризик зламати гарантії дошки |
| 3 | Free-scan доступний із loading-стану — гравець може встигнути натиснути Rescan безкоштовно, поки список ще вантажиться | Дрібний експлойт, не ламає економіку; фікс потребує окремого стану UI |
| 4 | Side-effect у `activeContractsProvider` — провайдер не лише читає, а й може ре-генерувати дошку | Архітектурна правка провайдерів; краще робити разом із переглядом стану |
| 5 | `fetchContractDetails` не перевіряє expiry — можна відкрити протермінований контракт за прямим переходом | Потребує узгодження з TTL-логікою дошки |

## Технічний борг, виявлений на кроці 08

| Тема | Суть |
| ---- | ---- |
| Міграції БД | `DatabaseHelper._migrate()` — drop-and-recreate **усіх** таблиць, включно з `accounts`/`profiles`. Будь-яке підняття `_dbVersion` стирає збереження гравця. Прийнятно для альфи, неприйнятно з моменту, коли з'являться реальні гравці. Потрібні інкрементальні `ALTER TABLE`. |
| Мок асетів у тестах | Винесено в `test/helpers/async_widget_harness.dart` для трьох виправлених файлів, але `step03_ux_test.dart` і `step04_news_calc_test.dart` досі несуть власні копії. Звести до хелпера. |
| `google_fonts` у рантаймі | Share Tech Mono тягнеться з мережі при першому запуску (рішення кроку 05). Офлайн перший старт покаже фолбек-шрифт, а тести змушені підсовувати підміну. Локальний ttf зняв би і мережеву залежність, і милицю в тестах. |

## Медіа та розмір APK

- **Оптимізація ваги APK:** Стиснення BGM MP3 бітрейту з 320/256 kbps до 128 kbps (зменшить APK з 104 МБ до ~35 МБ).
- Усі поточні аудіо/графічні активи — плейсхолдери; перед продакшином перезбираються
(див. `CREDITS.md`). Сюди ж: кросфейд між треками плейлиста (поточний перехід різкий,
`Bgm` API не дає накладання — потрібен другий плеєр).
