#### Тестер 2 (Android 13, Samsung Galaxy A53)
- **Зрозумілість:** "Панель Attack Forecast просто супер — відразу видно шанси на злам."

#### Тестер 3 (Windows 11 / Android 12, Xiaomi Redmi Note 11)
- **Зрозумілість:** "Навігація зручна, кнопки налаштувань під рукою."

- **Продуктивність:** "Жодних лагів, відео-фон дуже красивий."

## 3. Систематизований аналіз за темами

1. **Фан та динаміка міні-гри (Sniffer):**
   - Механіка стабільна й аддиктивна на перших 5-7 атаках.
   - Для утримання інтересу після 10+ атак потрібно підвищити скейлінг швидкості кульок через параметр `defense` цілей у балансі v2.
2. **UX та Зрозумілість:**
   - Впровадження палітри Classic Terminal, єдиних токенів та екрана Attack Forecast оцінено дуже високо (сер. оцінка зрозумілості 8.8/10).
3. **Економіка та баланс:**
   - Економічний глухий кут повністю ліквідовано. Продаж та екстрений скан функціонують без збоїв.
   - За фідбеком відкалібровано нагороди на середніх контрактах (Lvl 3-6) для більш відчутного відчуття накопичення багатства.
4. **Вага APK та Медіа:**
   - Розмір 104 МБ зумовлений несжатими аудіо-треками BGM у `assets/audio/`. Зафіксовано як пункт для оптимізації в Alpha 3.0 (компресія MP3 бітрейту до 128 kbps скоротить вагу до ~35 МБ).
5. **Стабільність:**
   - **0 падінь (zero crashes)** під час усіх плейтестів.
