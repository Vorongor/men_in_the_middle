## Оцінка за областями

### 1. Виправлення багів тест-звіту Alpha 1.0 (Баги №1–8) — 100% ✅

1. **№1 Краш міні-гри (`LateInitializationError: paddle`):** Усунуто у [sniffer_game.dart](../../lib/game/sniffer/sniffer_game.dart) через ініціалізаційні варти та відкладений розмір; overflow-помилки на Attack Prep виправлено через `Expanded` з м'яким перенесенням.
2. **№2 Економічний глухий кут:** Додано продаж власного софту й заліза у Workshop ([inventory_repository.dart](../../lib/repos/inventory_repository.dart)), авто-поновлювану дошку контрактів (TTL 24h) та безкоштовний `Free Emergency Scan` на 0 балансі з гарантією страхових контрактів.
3. **№3 Повідомлення перекривають кнопки:** Усі снекбари уніфіковані через хелпер `showAppSnack()` зі стилем `SnackBarBehavior.floating`.
4. **№4 Вильоту з екрана предмета після апгрейду немає:** Workshop Item оновлює характеристики in-place без виклика `Navigator.pop()`.
5. **№5 Доступ до налаштувань з будь-якого екрана:** Додано іконку Settings у шапці AppBar усіх ігрових екранів та меню паузи у Sniffer.
6. **№6 Керування новинами:** Додано позначення прочитаного, поштучне видалення та масове розчищення прочитаних статей.
7. **№7 Калькуляція сили атаки:** Додано модуль `AttackForecastPanel` на екрані підготовки атаки з розрахунком відсотка ефективності та порівняння потужності.
8. **№8 Кольорова гама та шрифти:** Впроваджено єдину дизайн-систему: палітра `Classic Terminal` HSL, заголовний шрифт **GeistPixel**, висококонтрастні стилі даних **Share Tech Mono**.

### 2. Візуальна ідентичність та Медіа — 100% ✅

- **Брендинг:** Створено та налаштовано офіційну іконку застосунку ([app_icon.png](../../assets/branding/app_icon.png)), іконку для Windows (`app_icon.ico`) та нативний splash-екран (`flutter_native_splash`).
- **Аудіо:** Інтегровано 11 фонових аудіо-треків BGM та 5 звукових ефектів SFX через `media_kit`. Додано `AudioRouteObserver` для плавних фонових аудіо-переходів між хабом та екранами.
- **Іконки:** Додано пресети іконок для цілей, місій, обладнання та навігації.

### 3. Тести та CI — 100% ✅

- Знайдено корінну причину зависання widget-тестів (дедлок I/O БД у зоні FakeAsync).
- Усі три раніше виключені файли тестів полагоджені за допомогою `tester.runAsync()` та допоміжного harness `settleAsync()`.
- **113 / 113 тестів проходять успішно** локально та у CI.
- Додано `timeout-minutes: 20` до CI workflow в `.github/workflows/ci.yml`.

### 4. Фізичний плейтест та Баланс v2 — 100% ✅

- Проведено живий плейтест на реальних Android-смартфонах та Windows ПК. Зафіксовано **0 падінь**.
- Створено посібник тестувальника [tester_guide.md](tester_guide.md) та збірник нотаток плейтесту [alpha_2_0_playtest_notes.md](alpha_2_0_playtest_notes.md).
- Піднято версію контенту `ContentSeeder.currentContentVersion = 4`.
- Підтверджено збалансованість ігрового циклу через безголовий симулятор `tool/simulate.dart` (300 атак) та `tool/simulate.dart 10`.
