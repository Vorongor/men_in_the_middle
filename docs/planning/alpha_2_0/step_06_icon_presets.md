# Крок 06 — Пресети іконок: предмети, цілі, місії, навігація

**Статус: ⬜ не розпочато** · Залежності: крок 05 (палітра для стилю іконок)
**Вхідні дані:** [general_alpha_2_0.md](general_alpha_2_0.md) (крок 06), [design_tokens.md](../../design/design_tokens.md) (створюється кроком 05)

## Мета

Кожен предмет, ціль, місія і розділ хаба має іконку в єдиному стилі. Додавання нового предмета в JSON автоматично підхоплює іконку за ключем — пайплайн, а не разова розстановка картинок.

## Контекст

- `assets/images/ui/` порожній і **прибраний із pubspec** CI-hotfix-ом (крок 08/загальний план) — цей крок повертає його з реальним вмістом.
- JSON-каталоги (`software_items`, `hardware_items`, `target_types`, `mission_types`) не мають поля іконки; списки Store/Market/Workshop/Target Board — суто текстові.
- Хаб (Screen 3) навігує 6 розділами — зараз без іконок або з системними Material-іконками (`Icons.*`), як і статусні показники (epts, exp, wanted, trust).

## Задачі

### 6.1 Пайплайн `icon_key`

- [ ] Додати опційне поле `icon_key` у 4 JSON-каталоги; `ContentSeeder` пише його в БД (міграція схеми: +1 версія, `ALTER TABLE ... ADD COLUMN icon_key TEXT`), моделі (`SoftwareItem`, `HardwareItem`, `TargetType`, `MissionType`) отримують поле.
- [ ] **Fallback-ланцюжок** (щоб контент можна було наповнювати поступово): `icon_key` предмета → дефолтна іконка його типу (`soft_type`/`hw_type`/`target_type`/`mission_type`) → generic-іконка. Відсутній файл не валить UI.
- [ ] Тест у `content_pipeline_test.dart`: кожен непорожній `icon_key` з JSON відповідає наявному файлу в `assets/images/ui/icons/` (ловимо биті посилання на CI, не в рантаймі).

### 6.2 Віджет

- [ ] `lib/widgets/app_icon.dart`: `AppIcon(iconKey, {size, color})` — інкапсулює шлях `assets/images/ui/icons/<key>.png`, fallback-ланцюжок і фарбування в колір з токенів (іконки — монохромні маски, колір задає контекст: акцент/приглушений/danger).

### 6.3 Набір v1 (пресет)

- [ ] Мінімальний комплект (27 файлів): 4 типи софту (Phishing/Bruteforce/DDoS/Exploit) · 5 типів заліза (CPU/RAM/NET/GPU/IO) · 7 типів цілей · 5 типів місій · 6 навігаційних (Profile, Targets, Store, Market, Workshop, News).
- [ ] Додатково (за наявності ресурсу): 4 статусні (epts, exp, wanted, black_trust) для шапки профілю/хаба.
- [ ] **Джерело і ліцензія:** один пак в одному стилі. Рекомендація: game-icons.net (CC BY 3.0) — монохромні, тематика підходить; атрибуція обов'язкова у новому `CREDITS.md`. Альтернатива — згенерований набір; змішувати джерела заборонено (стилістичний розповз — головний ризик кроку).
- [ ] **Формат:** PNG (білий гліф на прозорому) у 3 щільностях (1x/2x/3x через `assets/images/ui/icons/2.0x/...`) — без нової залежності `flutter_svg`. Розмір базовий 24×24/48×48. Рішення зафіксувати в доці.
