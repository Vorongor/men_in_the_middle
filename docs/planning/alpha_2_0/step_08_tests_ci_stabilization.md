## Summary

### Головний результат

`flutter test` **без жодних виключень**: було «висить вічно» → стало **113/113 за 18 секунд**.
`flutter analyze` — 0 issues. Обрано **варіант А**: усі три тести полагоджені й повернуті
в загальний прогін, ізолювати нічого не довелось.

### Корінна причина зависань — знайдена

Це не був ані конфлікт двох Flutter SDK (гіпотеза А), ані файлова БД (гіпотеза Б).

**Реальний I/O бази всередині тіла `testWidgets` спричиняє дедлок ізоляту.**
Тіло `testWidgets` виконується у зоні FakeAsync, чий годинник рухається лише коли тест
пампає. Справжня асинхронна операція sqflite там ніколи не завершується, і `await` на ній
блокує event loop **намертво** — тому не спрацьовував навіть `--timeout`: таймаут дарт-тесту
сам є таймером на заблокованому циклі. Звідси й характерний симптом: нуль виводу, нуль
діагностики, просто тиша.

Доведено бісекцією на пробному файлі:

| Проба | Результат |
| ----- | --------- |
| `register()` у звичайному `test()` | ✅ проходить |
| той самий `register()` у `testWidgets()` | 🔴 вічне зависання |
| той самий код у `testWidgets` + `tester.runAsync()` | ✅ проходить |

**Фікс:** тіло загорнуто в `tester.runAsync()`, який виходить із зони FakeAsync.
Патерн не новий для проєкту — `step03_ux_test.dart` уже так робив, тому й проходив;
три «прокляті» файли просто його не застосовували.

### Що ховалося під зависанням

Тести не запускались давно, тож накопичили відкладені поломки — кожна вилізла аж
після зняття дедлоку:

1. **Мок асетів не знав про `economy.json`** (додано на кроці 05) — DB-сідер падав.
2. **`AssetManifest.bin` повертався як null.** Мок підміняє весь канал асетів, включно
   з запитами самого фреймворку; null ламав резолв шрифтів і екран не рендерився зовсім.
3. **`google_fonts` кидав виняток під час білда** — Share Tech Mono тягнеться з мережі,
   а в тестах `allowRuntimeFetching = false`. Підставляємо байти локального GeistPixel.
4. **Застарілі очікування після міграції кроку 05:** тести чекали `PHISHING MAILER V1`
   і `LOCAL MERCHANT PC`, а дизайн-система прибрала ручний uppercase — рендериться
   `Phishing Mailer v1`. Це рівно той ризик, який крок 05 і передбачав, просто ніхто
   не міг його побачити.
5. **`Navigator` перевикористовувався між `pumpWidget`** — Flutter оновлював попередній
   елемент `MaterialApp` на місці, зберігаючи стек маршрутів від старого `home:`, тож
   `onGenerateRoute` не викликався і екран не монтувався. Лікується свіжим `key`.
6. **`settleAsync` мусить пампати з тривалістю** — голий `pump()` лише перебудовує
   дерево й не рухає годинник анімацій, тож маршрут завмирав на півпереході.

Спільну інфраструктуру винесено в `test/helpers/async_widget_harness.dart`
(мок каталогу + `settleAsync`). Назва навмисне **не** закінчується на `_test.dart`:
інакше раннер підхоплює хелпер як тест-файл без тестів і пас червоніє.

### Борг код-рев'ю (8.5)

- **`EconomyTuning.defaults`** + `EconomyTuning.load(DatabaseExecutor)` — прибрано
  6 копій літерала й 4 копії `query meta + jsonDecode`. Критерій grep виконано.
- **Єдина формула ціни продажу:** `lib/game/economy/sell_pricing.dart` — чисті функції
  **без залежності від Flutter**, бо симулятор працює під голим `dart run` і не може
  імпортувати шар репозиторіїв. Тепер транзакція, лейбл `SELL · +N`, діалог підтвердження
  і симулятор рахують однаково.
- **Симулятор чесніший:** ціна продажу береться зі спільної функції та `sell_ratio` з
  economy.json (було зашите `0.5`); театральний `if (1 <= 1) throw` замінено на перевірку
  реального складу стартового інвентаря; жорстка перевірка віх прогресії тепер виконується
  лише на повному прогоні — `simulate.dart 10` більше не падає (обидва режими exit 0,
  Level 5 на #15 збережено).
- П'ять відкладених знахідок по логіці цілей → `docs/planning/alpha_3_0/backlog.md`.
