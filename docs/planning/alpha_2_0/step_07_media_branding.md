# Крок 07 — Медіа-пресети та брендинг: іконка, splash, SFX, BGM

**Статус: ⬜ не розпочато** · Залежності: крок 05 (палітра), крок 06 (стиль графіки)
**Вхідні дані:** [general_alpha_2_0.md](general_alpha_2_0.md) (крок 07), рев'ю alpha 1.0 («Аудіо/візуал — найслабша область»)

## Мета

Гра стає впізнаваною і «звучною»: власна іконка застосунку, темний splash замість білого спалаху Flutter, реальні звуки на всі вже підключені SFX-хуки, окремий трек для ігрового хаба. Це закриває блокери публічної роздачі, названі в рев'ю alpha 1.0.

## Контекст (з коду)

- `flutter_launcher_icons ^0.14.3` і `flutter_native_splash ^2.4.5` **вже в dev_dependencies** ([pubspec.yaml:45-46](../../../pubspec.yaml)) — не сконфігуровані й не запущені.
- SFX-константи визначені в [constants.dart:23-31](../../../lib/utils/constants.dart): `sfx_catch/hit/win/lose/purchase/upgrade/level_up.mp3` — **7 файлів**, жодного не існує; `AudioService.playSfx()` свідомо no-op-ить помилку. Хуки вже розставлені: міні-гра (catch/hit/win/lose), покупки (purchase), апгрейд і продаж (upgrade), левел-ап (level_up).
- BGM: один трек `main_theme.mp3`, грає від меню і далі скрізь (рішення кроку 10 alpha 1.0 — «немає окремого хаб-треку»).
- APK 66.3 МБ, головний внесок — media_kit заради відео-фону меню (`matrix_bg.mp4`).

## Задачі

### 7.1 Іконка застосунку

- [ ] Майстер-арт 1024×1024 у стилі гри (палітра токенів кроку 05; проста читабельна форма — термінал/маска/вузол мережі). Джерело: власний арт або згенерований — зафіксувати в CREDITS.md.
- [ ] Конфіг `flutter_launcher_icons` у pubspec: Android (adaptive: foreground + темний background), Windows (.ico). Запуск, перевірка обох платформ.
- [ ] Перевірити іконку на світлому/темному лончері Android (adaptive маски обрізають краї — лишати safe zone).

### 7.2 Splash-екран

- [ ] Конфіг `flutter_native_splash`: фон = токен `bg`, по центру — логотип/іконка. Android 12+ секція окремо (`android_12:`).
- [ ] Згенерувати, перевірити: холодний старт Android і Windows без білого спалаху.

### 7.3 SFX-пак (7 файлів)

- [ ] Підібрати з CC0-джерел (kenney.nl «Interface Sounds»/«Digital Audio», freesound CC0): короткі (<0.5с) синтетичні кліки/бліпи в кіберпанк-тоні. Іменувати точно за константами `AppAudio` — код не змінюється.
- [ ] Нормалізувати гучність пака (однаковий рівень, без кліпінгу); формат mp3 (як константи) або узгоджено перейменувати на .wav і оновити константи — одне рішення на весь пак.
- [ ] Прогнати всі 7 тригерів вручну: лов/влучання/перемога/поразка в міні-грі, покупка в Store і Market, апгрейд+продаж у Workshop, левел-ап. `effects_volume`/Mute All із Settings впливають (логіка вже є — перевірити).
- [ ] `CREDITS.md`: джерело й ліцензія кожного файлу/пака.

### 7.4 BGM хаба

- [ ] Другий трек (CC0/CC-BY: несквапний ембіент/синтвейв ~1-2 хв loop) → `assets/audio/hub_theme.mp3`, константа в `AppAudio`.
- [ ] `AudioService`: перемикання треку при вході в хаб (після auth) і назад у меню; перехід — короткий fade-out/fade-in, без різкого обриву; гучність — та сама формула `general × music`.
- [ ] Loop без чутного шва (перевірити 2-3 повних цикли).

### 7.5 Вага збірки — рішення, не переробка

- [ ] Заміряти внесок фактично: розмір APK з/без `matrix_bg.mp4` + media_kit (експериментальна гілка, не мержити).
- [ ] Зафіксувати рішення у цьому файлі (Summary): «залишаємо відео-фон» або «міняємо на шейдер у кроці N» — фінальний вибір робиться після фідбеку тестерів про розмір (крок 09). У цьому кроці нічого не видаляти.

### 7.6 Документація

- [ ] `docs/design/media_presets.md`: перелік усіх медіа-активів (іконка, splash, 7 SFX, 2 BGM, відео-фон) з джерелом, ліцензією, форматом і місцем використання.

## Критерії приймання

- [ ] На Android-лончері та в Windows-таскбарі — власна іконка; холодний старт — темний splash.
- [ ] Повний core loop проходить зі звуком на кожній ключовій дії; Mute All дає повну тишу.
- [ ] У хабі грає окремий трек; повернення в головне меню повертає меню-трек.
- [ ] `CREDITS.md` покриває 100% сторонніх активів; `flutter analyze` — 0 issues; release-білди обох платформ збираються.
