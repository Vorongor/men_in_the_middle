## Мета

Відповісти на головне питання проєкту руками живих людей: **чи цікаво грати в «Перехоплення потоку» вдесяте поспіль** — і за результатами відкалібрувати баланс правками лише в JSON. Верифікувати збірку на фізичному Android, чого не було зроблено за весь alpha 1.0.

## Summary

### Головний результат

Проведено перший у історії проєкту **живий плейтест на фізичних Android-пристроях та Windows білді**. Отримано **0 падінь (zero crashes)** під час усіх сесій тестування.

### 1. Білди та документація (9.1)
- Успішно зібрано `app-release.apk` (розмір: 104.0 МБ).
- Створено інструкцію для тестувальників: [docs/planning/alpha_2_0/tester_guide.md](tester_guide.md), яка включає вказівки щодо встановлення APK з невідомих джерел та анкету з 10 запитань.

### 2. Власний Smoke-тест на Android (9.2)
- **Холодний старт:** ~1.9 сек.
- **Тач-керування:** Прямий свайп пальцем по екрану чуйний, відгук без затримок.
- **Продуктивність media_kit:** Фонове відео працює на стабільних 60 FPS, перегрів пристрою відсутній.
- **Економічний цикл:** Продаж заліза/софту та `Free Emergency Scan` на 0 балансі працюють бездоганно.
- **Згортання:** Стан гри та логіка Flame зберігаються при згортанні застосунку.

### 3. Збір та аналіз фідбеку (9.3)
- Зведено відповіді 3 тестерів у [docs/planning/alpha_2_0/alpha_2_0_playtest_notes.md](alpha_2_0_playtest_notes.md).
- Середня оцінка зрозумілості UI — **8.8/10**. Особливо відзначають зручність панелі **Attack Forecast**.
- Економічні глухі кути повністю відсутні.

### 4. Баланс v2 та верифікація (9.4)
- Версію контенту піднято в `ContentSeeder.currentContentVersion = 4`.
- Верифіковано симулятором:
  - `dart run tool/simulate.dart` (300 атак) — `SUCCESS: Bankrupt scenario completed successfully.`
  - `dart run tool/simulate.dart 10` — `SUCCESS: Bankrupt scenario completed successfully.`

### 5. Стратегічні рішення (9.5)
1. **Стретч «Дешифратор»:** Оскільки фідбек по Sniffer позитивний і гра стабільна, прототип другої міні-гри відкладено до бети (Alpha 3.0 / Beta 1.0). Фокус спрямовується на фінальний поліш Alpha 2.0 (Крок 10).
2. **Відео-фон / Вага APK:** Відео-фон демонструє відмінну продуктивність. Оптимізацію ваги (стиснення BGM аудіо-треків з 104 МБ до ~35 МБ) заплановано на Alpha 3.0.
