**Варіант 1:** Classic Terminal (Класичний "Матричний" стиль)
Це безпрограшний варіант, який одразу каже гравцеві: "Ти в системі". Він будується на глибокому чорному та відтінках неонового зеленого. Щоб очі не втомлювалися, чистий зелений використовується лише для акцентів :

    - Background (Фон): #0A0A0C — Дуже глибокий, майже чорний колір із ледь помітним холодним відтінком.
    - Surface (Карточки, меню): #121417 — Трохи світліший чорний для виділення блоків (наприклад, товарів у Grey Store).
    - Primary (Основний акцент): #00FF41 — Класичний хакерський зелений. Для кнопок "Start", ліній підключення в міні-іграх.
    - Secondary (Другорядний): #008F11 — Приглушений зелений для неактивних елементів або фонових сіток.
    - Text (Текст): #E0E0E0 — Світло-сірий (ніколи не використовуйте чистий #FFFFFF на чорному, це ріже очі).
    - Alert/Wanted (Помилка/Розшук): #FF003C — Агресивний червоний для відображення зростання рівня wanted або провалу місії.

**Варіант 2:** Synthwave / Modern Cyberpunk
Більш сучасний підхід, який часто використовується в іграх жанру кіберпанк. Він базується на контрасті глибокого синього та яскравих неонових кольорів (бірюзового і пурпурового):

    - Background (Фон): #0B0C10 — Темний вугільно-синій.
    - Surface (Карточки, меню): #1F2833 — Синьо-сірий колір, який створює відчуття "металу" або пластику серверних стійок.
    - Primary (Основний акцент): #66FCF1 — Електричний бірюзовий. Дуже яскравий, ідеально підходить для прогрес-барів фаєрволу та активних цілей.
    - Secondary (Другорядний): #45A29E — Спокійніший бірюзовий для звичайних кнопок та рамок.
    - Text (Текст): #C5C6C7 — Сріблясто-сірий.
    - Alert/Wanted (Помилка/Розшук): #F00699 — Неоновий рожевий/пурпуровий для екрану облави Кіберполіції.

**Варіант 3:** Corporate Stealth (Суворий монохром)
Ця палітра створює відчуття роботи в серйозній промисловій або урядовій системі. Використовуються відтінки сірого з одним дуже яскравим контрастним кольором (бурштиновим), як у старих монохромних моніторах або інтерфейсах ОС:

    - Background (Фон): #161618 — Темний матовий сірий.
    - Surface (Карточки, меню): #222225 — Світліший матовий сірий для розділення зон на Home Page.
    - Primary (Основний акцент): #F5A623 — Бурштиновий (Orange-Yellow). Створює ретро-футуристичний настрій.
    - Secondary (Другорядний): #595959 — Середній сірий для рамок та неактивних іконок.
    - Text (Текст): #D8D8D8 — Теплий світло-сірий.
    - Alert/Wanted (Помилка/Розшук): #D0021B — Темно-червоний. Ця палітра робить червоні помилки дуже помітними та загрозливими.
