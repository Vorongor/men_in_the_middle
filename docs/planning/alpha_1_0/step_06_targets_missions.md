# Крок 06 — Target Board і генерація місій

**Статус: ✅ виконано** · Залежить від: 03, 04

## Мета

Дошка цілей (5.1) показує згенеровані під гравця контракти; деталі цілі (5.2) — реальні дані: тип, захист, нагорода, ризик, рекомендований софт. Хардкод видалено.

## Модель контракту

Контракт = `target_template` + згенерована варіація. Зберігаємо активний набір у таблиці:

- [ ] `active_contracts`: profile_id, target_template_id, mission_type_id, defense (варіація ±15%), epts_reward, trust_reward, expires_at, is_completed

## Задачі

### 6.1 Генератор контрактів

- [ ] `ContractGenerator.refresh(profile)`: 5–7 контрактів із `target_templates` де `required_level <= level+1`; хоча б 1 «легкий» (нижче рівня) і 1 «складний» (level+1)
- [ ] mission_type відповідає типу цілі (за матрицею концепту), нагорода = base × mission.base_reward_mult × варіація
- [ ] Регенерація: при першому вході за день АБО кнопкою за невелику плату epts (анти-фарм); виконаний контракт зникає
- [ ] Seed генератора зберігати в attack_log/contract — для відтворюваності багів

### 6.2 Target Board — Screen 5.1

- [ ] Список контрактів: назва, тип цілі, difficulty-бейдж (порівняння defense із software_power гравця: LOW/MEDIUM/HIGH), нагорода epts
- [ ] Прев'ю на Home Page (3 верхні контракти) — з того самого провайдера
- [ ] Порожній стан + кнопка refresh

### 6.3 Target Detail — Screen 5.2

- [ ] Повні дані: опис, base_defense, trace_speed типу, risk_multiplier, нагороди (epts + black_trust), required_level
- [ ] Блок «Рекомендований софт»: тип софту з damage_mult ×2 за матрицею ефективності; показати, чи має гравець такий софт
- [ ] Кнопка PREPARE ATTACK → Screen 7.1 з типізованим `AttackArgs(contractId)`; заблокована, якщо рівень не досягнуто

### 6.4 Тести

- [ ] Unit: генератор — діапазон рівнів, кількість, розкид нагород, детермінованість за seed
- [ ] Widget: Target Board показує контракти; difficulty-бейдж рахується правильно

## Критерії приймання

- Новий гравець бачить 5–7 посильних контрактів; після виконання контракт зникає, дошка поповнюється
- Difficulty чесно відображає співвідношення сил
- Home Page-прев'ю і повна дошка завжди синхронні
