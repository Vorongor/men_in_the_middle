# Catalog Data Catalog

This directory contains the game configuration and data catalogs seeded into the database on startup.

## Files

- `target_types.json` - Describes target classes, their trace speed, and risk factors.
- `mission_types.json` - Describes mission templates, rewards, and requirements.
- `software_items.json` - Details software tools available for purchase and their upgrade strategies.
- `hardware_items.json` - Details hardware components available for purchase.
- `target_templates.json` - Reusable templates representing contract target servers.
- `effectiveness.json` - Lookup matrix defining software type vs target type damage/trace modifiers.
- `level_curve.json` - Experience requirements for player level progression.
- `economy.json` - Global economy parameters (refresh fees, sell ratios, contract TTL, insurance floor).
